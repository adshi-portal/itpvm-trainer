# ІТПВМ · Тренажер практичних робіт

Вебтренажер для виконання практичних робіт 1–8 з дисципліни **«Інформаційні технології в проєктуванні та виробництві машин»** (ВНТУ, кафедра ТАМ, третій освітньо-науковий рівень, спеціальність G9 «Прикладна механіка»).

Зміст побудовано за **задачником на 10 варіантів** і **методичними вказівками до практичних робіт** (критерії оцінювання, мета робіт, контрольні положення).

## Можливості

**Для здобувача**
- профіль: ПІБ, номер здобувача (набір задач) і варіант вихідних даних 1–10;
- розподіл задач: здобувач № 1 — задачі 1, 4, 7, 8; № 2 — 2, 5, 7, 9; № 3 — 3, 6, 7, 10 (задача 7 спільна); можна показати всі 10 задач теми;
- для кожної задачі — структурована форма відповіді: таблиці, тексти з лічильником слів, код, завантаження схем (PNG/JPG з draw.io, Visio тощо), матриці зважених оцінок;
- **автоматична перевірка розрахунків** із фіксацією кількості спроб:
  - ПР 1, задача 4 — інтегральний показник цифровізації за 13 напрямами;
  - ПР 5, задачі 1, 4, 5 — описові статистики, x̄ / s / CV за товщинами, степенева апроксимація σ = a·tᵇ і R² (з графіком);
  - ПР 8, задачі 3, 4, 5 — коефіцієнт запасу міцності, допустиме напруження;
- тест самоперевірки (5 запитань до кожної роботи) з поясненнями;
- декларація використання AI (вимога академічної доброчесності) і висновки;
- автозбереження в браузері; файл для здачі `.json`; **звіт для друку / PDF** з титульним аркушем за додатком А методичних вказівок.

**Для викладача** (меню «Перевірка робіт», PIN за замовчуванням — `2026`)
- завантаження одного або багатьох файлів здачі перетягуванням;
- зведена таблиця: повнота виконання, результати автоперевірки, тест, декларація AI, цілісність файлу;
- перегляд відповіді з **еталонними значеннями** поруч зі значеннями здобувача;
- бали за критеріями методичних вказівок (сума 100), коментар, друк рецензії;
- вкладка «Ключі відповідей» для всіх 10 варіантів (ПР 5, ПР 8, ПР 1);
- відомість CSV (відкривається в Excel): здобувачі × ПР 1–8, а також детальний CSV із балами за критеріями.

## Розміщення на GitHub Pages

1. Створіть репозиторій на GitHub (наприклад, `itpvm-trainer`), зробіть його публічним.
2. Завантажте вміст цієї папки в корінь репозиторію (кнопка **Add file → Upload files** або `git push`). Файл `.nojekyll` теж має бути в корені.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, гілка `main`, папка `/ (root)` → **Save**.
4. За 1–2 хвилини тренажер буде доступний за адресою `https://<ваш-логін>.github.io/itpvm-trainer/`. Цю адресу надайте здобувачам.

Збирати чи встановлювати нічого не потрібно: це статичний сайт (HTML + CSS + JavaScript без залежностей). Тренажер також працює локально — достатньо відкрити `index.html` у браузері.

## Як здобувачі здають роботи

1. Виконують роботу → внизу сторінки роботи натискають **«Файл для здачі (.json)»**.
2. Надсилають файл викладачу (Moodle, пошта, Teams).
3. Викладач відкриває «Перевірка робіт» і перетягує отримані файли.

Дані зберігаються лише в браузері користувача (localStorage), на сервер нічого не передається. Для перенесення на інший комп'ютер — «Експортувати всі роботи» → «Відновити з файлу».

## Налаштування

Увесь зміст — у файлі `js/data.js`:

- `config.taskSets` — розподіл задач між здобувачами;
- `config.teacher`, `config.year` — дані для титульного аркуша;
- `works[].tasks` — формулювання задач і форми відповідей; `works[].rubric` — критерії оцінювання; `works[].quiz` — тестові запитання;
- `pr1Directions` — перелік напрямів цифровізації для ПР 1 (задача 4);
- `pr5` — вихідні дані ПР 5 за варіантами.

### Зміна PIN викладача

1. Відкрийте тренажер, натисніть F12 → вкладка **Console**.
2. Виконайте `trainerHash("ваш-новий-PIN")` — отримаєте рядок із 16 символів.
3. Вставте його в `js/data.js` у поле `teacherPinHash` і оновіть файл у репозиторії.

Змініть також `config.salt` на власний рядок — це ускладнює підробку контрольної суми файлів здачі.

> Обмеження. Сайт статичний і публічний, тому PIN і контрольна сума є навчальним бар'єром від випадкових змін, а не криптографічним захистом. Еталони розрахунків обчислюються в браузері. Оцінки викладача зберігаються лише в його браузері — регулярно вивантажуйте відомість CSV.

## Структура

```
index.html        — сторінка застосунку
css/style.css     — оформлення (палітра курсу: темно-синій, золотий, кремовий, світло-блакитний)
js/data.js        — зміст курсу: варіанти, задачі, критерії, тести, налаштування
js/calc.js        — статистика, апроксимація, еталонні значення, контрольна сума
js/app.js         — інтерфейс здобувача, автоперевірка, експорт, друк звіту
js/teacher.js     — режим викладача
.nojekyll         — вимикає обробку Jekyll на GitHub Pages
```
